# Changelog

All notable changes to the **Burgundy Pro** extension will be documented in this file.

## [1.0.3] - 2026-11-14

### Fixed
- Fixed icon asset registration and forward-slash paths in manifest for seamless Visual Studio Marketplace rendering.

## [1.0.2] - 2026-11-14

### Changed
- Replaced external image hosting with permanent GitHub raw image URLs pointing to the `images/` folder in the official repository (`shamsulhaq08/burgundy-pro`).
- Standardized all README images to Markdown syntax (`![description](url)`).
- Updated package repository field and verified distinct previews for Burgundy Pro and Burgundy Soft.

## [1.0.1] - 2026-11-14

### Changed
- Updated README images to use CDN-hosted HTTPS URLs.

## [1.0.0] - Initial Release

### Added
- **Burgundy Pro**: Deep, rich burgundy dark theme with wine-red accents and dark charcoal backdrop.
- **Burgundy Soft**: Velvet, lower-contrast burgundy theme optimized for long, eye-fatigue-free coding sessions.
- Full syntax highlighting coverage for 20+ languages.
- Complete workbench styling and official 128x128 icon.
